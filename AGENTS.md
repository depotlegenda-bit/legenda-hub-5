# Project rules
- Implement HPP as an authenticated React page using the existing menu permission registry, so access stays consistent with the rest of the application.
- Keep HPP calculations and CSV parsing in its dedicated library and persist workspaces keyed by outlet in Cloud with version-checked updates and existing HPP permission validation, so outlet data is isolated and concurrent edits cannot silently overwrite each other; do not change inventory data.
- Serve fixed HPP CSV templates from public/downloads through a shared download control, so input forms deliver same-origin files without browser generation.
